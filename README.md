# scummvm-tng-build
Windows build of ScummVM with TNG Interactive Technical Manual compatibility patches

This repository contains compatibility patches and build automation for running the
1995 *Star Trek: The Next Generation Interactive Technical Manual* with ScummVM.
It does not contain the original game data. A lawfully owned original CD-ROM or ISO
is required.
